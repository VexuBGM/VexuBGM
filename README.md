### 🗣️ Debatera

**An all-in-one platform for organizing and running debate tournaments.**

Debatera brings tournament registration, teams, pairings, judging,
online debate rooms, ballots, standings and results into one system.

The platform was used in **real debate competitions**, giving me experience
building software around actual users, organizers and live-event requirements.

**Tech:** Next.js • React • TypeScript • PostgreSQL • Prisma • Tailwind CSS • Clerk • Stream

> 📦 Development has concluded and the project is now archived, but the source code and live deployment remain available.
